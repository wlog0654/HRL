# HRL

炉石与 OW 的轻量快捷工具。开关游戏、快速重启、炉石拔线，一个悬浮按钮和托盘菜单就够了。

单个 EXE，免安装，无系统通知。

- **炉石开启／关闭／重启**：通过战网启动，启动后自动收起战网窗口。
- **炉石拔线**：点一下悬浮按钮，或按自定义快捷键，断开当前对局连接。
- **OW 开启／关闭／重启**：关闭时一并清理同目录的 NEAC 残留，避免战网一直显示“正在游戏中”；启动流程响应后收起战网。

## 使用

运行 `HRL.exe`，允许管理员权限。右键悬浮按钮或托盘图标，选择关闭、重启炉石或 OW。**游戏未运行时，点“重启”即可启动。** 等待期间可点“取消等待”。

炉石对局中，单击悬浮按钮或按 `Ctrl+Shift+R` 拔线。快捷键可在菜单中直接按键修改；按钮可拖动并记住位置，隐藏后快捷键仍然有效。

| 功能 | 路径怎么配置 |
| --- | --- |
| 拔线、日志清理 | 自动读取正在运行的炉石位置，无需手填 |
| 开启／重启炉石 | 首次选择战网的 `Battle.net.exe`；关闭无需配置 |
| 关闭／重启 OW | 首次选择 OW 的 `_retail_\Overwatch.exe`；开启、重启还需选择战网 |

路径保存在本机，支持中文和空格。软件移动或卸载导致路径失效时，会重新弹出选择框；取消选择不会关闭游戏。NEAC 路径自动取自所选 OW 目录，无需单独配置。

## 行为与限制

- 收起战网相当于点击窗口的叉，遵循战网自己的关闭设置；炉石需确认游戏窗口出现，OW 无需等到游戏窗口出现。
- 关闭、重启会结束相应游戏进程；OW 清理仅限所选目录的 `OWNeacClient`（可能显示为 neacprotect）和 `NeacLoader`。
- 拔线不轮询网络连接，两秒内连按只算一次；无法确认唯一目标时拒绝操作，不注入 DLL、不读游戏内存、不改防火墙。
- 历史日志超过 256 MiB 时自动清理至约 192 MiB，保留当前与最新会话；不截断正在使用的日志。
- 不发系统通知。悬浮按钮显示简短状态，详细结果写入本地日志；快捷键冲突或保存失败时保留原设置。

Windows 10 / 11 x64，需要 .NET Framework 4.8。拔线只支持 IPv4 TCP，悬浮按钮建议配合窗口或无边框模式。

提示“已拔”只说明连接已关闭，不代表游戏已经重连成功。各区服和加速器环境无法全部验证，遇到问题请提 Issue。

1119 端口的对局连接需由游戏日志确认；日志不更新时请参阅[日志配置](docs/architecture.md#炉石日志配置)。历史日志清理不会解除游戏的单文件写入上限。

## 构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

会构建并测试，输出 `build\HRL.exe`。不需要 Visual Studio 或 .NET SDK。
